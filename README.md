# System Monitor

A lightweight system monitoring tool for tracking resource usage and system health.

## Overview

`system-monitor` provides real-time insights into CPU, memory, disk, and process metrics. Designed to be simple, extensible, and easy to integrate into dashboards or alerting pipelines.

## Features

- Real-time CPU, memory, and disk usage monitoring
- Process inspection and resource tracking
- Configurable collection intervals and thresholds
- Extensible collector architecture

> Project is in initial scaffolding — features above are planned/roadmap.
